# GymSkill

器械体操選手が練習を記録・共有・応援できる、スマートフォン優先のSNSアプリです。これはVersion 1のプロトタイプで、データはブラウザに保存されます。

## 起動

Node.js 20以上をインストールしてから、次を実行します。

```bash
pnpm install
pnpm dev
```

`http://localhost:3000` をブラウザで開いてください。

## 実装済み

- タイムライン、いいね、投稿詳細、コメント
- 技名・種目からの検索と関連する選手・投稿の表示
- 練習投稿作成（動画ファイル名の選択まで）
- 通知のUI
- プロフィールと技の状態登録（習得済み・練習中・習得したい）

## データ保存

投稿、コメント、いいね、登録技は `localStorage` の `gymskill-v1` キーに保存されます。ブラウザのサイトデータを削除すると初期状態へ戻ります。
